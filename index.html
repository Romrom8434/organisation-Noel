Associer deux personnes
Les deux personnes choisies apparaîtront sur une même ligne dans les tableaux récap (couple, parent + enfant, etc.). Une personne ne peut être associée qu'à une seule autre.
Regrouper par foyer
Les personnes d'un même foyer (ex. une famille) sont comptées comme une seule entité pour les comptes — pas de dette à suivre entre elles.
